Apps Script 설정 순서
  1. Google Sheets 새 스프레드시트 만들기
  2. 확장 프로그램 → Apps Script → Code.gs 내용 붙여넣기
  3. Code.gs 상단 SECRET_KEY와 OFFERING_EMAIL 수정
  4. setup() 함수 한 번 실행 (시트 자동 생성)
  5. 배포 → 새 배포 → 웹앱 → 모든 사용자 → 배포
  6. 생성된 URL을 위 입력창에 붙여넣고 저장
  7. 연결 테스트 → 성공 확인 후 사용
⚠️ 카메라 QR 스캔은 HTTPS 환경에서만 동작합니다. 로컬(file://)에서는 직접 입력을 사용하세요.
